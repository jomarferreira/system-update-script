# 🔄 System Update Script

## 🇧🇷 Descrição
Script em Bash desenvolvido para automatizar o processo de atualização do sistema Linux, executando comandos essenciais de atualização de pacotes de forma rápida e prática.

O **System Update Script** facilita a manutenção do sistema, reduzindo a necessidade de executar manualmente múltiplos comandos no terminal.

---

## 🇺🇸 Description
A Bash script designed to automate the Linux system update process by executing essential package update commands efficiently.

**System Update Script** simplifies system maintenance by reducing the need to manually run multiple terminal commands.

---

## 🚀 Funcionalidades | Features
- Atualização de pacotes do sistema  
- Execução automatizada via terminal  
- Simples e rápido  
- Redução de tarefas manuais
